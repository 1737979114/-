# astrbot_plugin_qq_group_admin · QQ 官方群管

对标「QQ群智能守护者」这类综合群管插件，但**适配 QQ 官方机器人（开放平台）**，不是 NapCat/OneBot 那套。

## 和参考插件的差异（重要）

参考插件跑在 NapCat 上，OneBot 接口有 28 项能力。QQ 官方开放平台的 v2 群管理接口少得多，下面按官方文档逐项核对过：

| 能力 | 官方 v2 | 说明 |
|---|---|---|
| 禁言 / 解禁 | 支持 | `POST /v2/groups/{id}/restrict_chat_setting` |
| 查询禁言状态 | 支持 | 含全员禁言模式 + 成员禁言列表 |
| 撤回消息 | 支持 | 仅限 2 分钟内 |
| 踢人 | 支持（内邀） | `batch_remove_members`，未开通返回 11253 |
| 全员禁言 | 仅查询有文档 | 设置接口按同路径尝试，失败会明确提示 |
| 群信息 / 成员列表 | 支持 | 适配器已提供，可在命令里扩展 |
| **群名片** | **无接口** | 官方没有修改群名片的 API |
| **群公告** | **无接口** | 同上 |
| **精华消息** | **无接口** | 同上 |
| **群打卡** | **无接口** | 同上 |

这五项不是我漏做，是官方根本没开放。硬写只会调不通。

## 实际功能

### 群管命令

```
@机器人 禁言 @某人 10分钟
@机器人 解除禁言 @某人
@机器人 踢人 @某人
@机器人 撤回           # 最近 1 条
@机器人 撤回 3         # 最近 3 条
@机器人 禁言状态
@机器人 全员禁言
@机器人 解除全员禁言
@机器人 群信息
@机器人 成员列表
@机器人 查成员 @某人
@机器人 黑名单
@机器人 入群申请
@机器人 我的id         # 查自己的 openid，用于配置管理员名单
```

禁言时长支持 `10分钟`、`2小时`、`30秒`、`1天`，纯数字按分钟算，范围 1 分钟到 30 天。

### AI 智能审核

开启后每条群消息都会过一遍：

1. **规则词**：配置里的词命中即处置，零延迟、零成本
2. **模型判定**：规则词没命中时，让模型判断是否广告、辱骂、诈骗、刷屏
3. **处置**：撤回 / 禁言 / 仅提醒，三选一
4. **豁免**：管理员、审核白名单、机器人自己都不会被审核

模型调用失败或超时会**放行**，不会因为接口抖动误杀群友。

审核记录会写进管理页的操作日志。

### 可视化管理后台

插件卡片打开后是**多页后台**，左侧导航六个页面：

| 页面 | 内容 |
|---|---|
| **总览** | 今日拦截/审核/放行/累计四张统计卡；近 7 天拦截与放行柱状图；违规类型分布；24 小时时段分布；最近拦截表 |
| **群管理** | 机器人收到过消息的群，按群展示拦截数和最后活跃时间，可一键查成员 |
| **违规记录** | 全部审核记录，支持按类型筛选、分页、标记「确认 / 误判」、删除 |
| **成员查询** | 输入群 openid 拉取成员列表（昵称、角色、入群时间） |
| **规则中心** | 关键词库，添加即生效，显示每条规则的命中次数 |
| **刷屏监控** | 监控开关、统计窗口、触发阈值，以及当前窗口内的高频用户排行 |
| **设置** | 分四个 tab：核心（开关 + 处置方式 + **生效平台** + **审核模型** + 凭据）、审核（提示词）、名单（管理员和白名单）、高级（超时/缓存/证书） |

**可以选机器人、选模型**：设置页「生效平台与审核模型」会列出当前 AstrBot 里所有平台实例和可用的对话模型，勾选哪个机器人就只在它上面生效（不勾选 = 所有 QQ 官方实例），审核模型可以单独指定，不选就跟随会话默认。

首页顶部的「数据仪表盘」是真实的按天统计，不是装饰图。所有数据来自插件运行时记录的审核事件。

**保存后立即生效**：设置写回 `data/config/` 并重建客户端，不用重载插件。AppSecret 回显是掩码，原样提交不会覆盖真实密钥。

## 前置条件

1. 机器人在群里是**管理员**
2. 填了 **AppID / AppSecret**（开放平台 → 开发设置）
3. 想用「撤回」要在管理端开启「**接收所有消息**」
4. 踢人需要内邀权限

### 内置词库

插件自带一份从「QQ群智能守护者」导出的违规词库，共 **45623 条**，按 12 类组织：

| 分类 | 条数 | 默认 |
|---|---|---|
| 政治敏感 | 30050 | 关 |
| 补充词库 | 7206 | **开** |
| 违规网址 | 5140 | 关 |
| 色情淫秽 | 552 | **开** |
| 反动言论 | 549 | 关 |
| 民生敏感 | 510 | 关 |
| 腾讯封禁 | 496 | **开** |
| 涉枪涉爆 | 438 | **开** |
| 贪腐相关 | 239 | 关 |
| 暴恐内容 | 175 | **开** |
| 其他违规 | 160 | **开** |
| 广告推广 | 108 | **开** |

默认启用约 **9134 条**，政治、违规网址、民生、反动四类默认关——它们的词太短太泛（比如 `.cn`、`&`），开了会疯狂误杀。需要的话在「规则中心 → 词库分类」里勾选，保存即刻生效。

匹配用**首字索引**：只检查消息里出现过的首字对应的词，单条消息耗时 0.03ms 左右，不会拖慢回复。

## 运行环境

- AstrBot 4.24.0 及以上
- 平台：`qq_official` / `qq_official_webhook`
- 依赖：`httpx`
- 其他平台发命令会提示「只支持 QQ 官方机器人」

## 限制

- 撤回 2 分钟是平台硬限制，插件缓存最近 30 条消息来定位目标，超时一样失败
- 管理员判断用 openid 名单，因为官方群消息不带发送者角色信息（`is_admin()` 在 qqofficial 下恒为 False）
- openid 和 QQ 号没有对应关系，名单只能填 openid
- 全员禁言的设置接口没有正式文档，失败时不会假装成功
- 操作日志只在内存，重启清空

## 配置

| 配置 | 默认 | 说明 |
|---|---|---|
| `enable` | 开 | 总开关 |
| `app_id` / `app_secret` | 空 | 开放平台凭据 |
| `admin_openids` | 空 | 允许执行群管命令的 openid，留空不限制 |
| `moderation_enabled` | 关 | 智能审核总开关 |
| `moderation_action` | `recall` | 处置方式：recall / mute / warn |
| `moderation_mute_seconds` | 600 | 审核禁言时长 |
| `moderation_keywords` | 空 | 规则词 |
| `moderation_whitelist` | 空 | 审核白名单 openid |
| `moderation_use_llm` | 开 | 是否让模型判断 |
| `moderation_prompt` | 空 | 自定义审核提示词，`{text}` 代表消息 |
| `llm_provider_id` | 空 | 审核用的模型 |
| `cache_messages` | 开 | 缓存消息用于撤回 |
| `cache_size` / `cache_ttl` | 30 / 600 | 缓存条数与保留秒数 |
| `timeout` | 10 | 接口超时 |
| `verify_ssl` | 开 | 证书校验 |
